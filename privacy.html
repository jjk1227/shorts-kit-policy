1. 누가 쓰는 앱인가

auto shorts kit(이하 "앱")은 운영자 한 사람이 자기 유튜브 채널을 운영하는 데 쓰는 개인용 도구입니다. 운영자 외의 사용자는 없으며, 일반 이용자의 개인정보를 수집하지 않습니다.

2. 접근하는 Google 사용자 데이터

운영자가 Google OAuth로 허용한 범위 안에서 운영자 본인의 계정에 대해서만 다음을 합니다.

  • YouTube Data API (youtube): 영상 업로드, 공개 상태와 예약 시각 설정, 썸네일 설정, 올린 영상의 상태 조회와 삭제
  • YouTube Analytics API (yt-analytics.readonly): 올린 영상의 조회수·시청 시간 등 성과 지표 읽기

3. 데이터의 보관

OAuth 토큰과 영상 ID·발행 시각·성과 지표 같은 작업 기록은 운영자가 관리하는 컴퓨터의 로컬 파일과 데이터베이스에만 저장됩니다. 앱 운영자가 운영하는 별도 서버는 없습니다.

4. 제3자 제공

Google 사용자 데이터를 판매하거나 광고에 쓰거나 제3자에게 넘기지 않습니다. 사람이 이 데이터를 열람하는 경우는 운영자가 자기 채널을 관리할 때뿐입니다.

5. Google API 서비스 정책 준수

이 앱이 Google API로 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

6. 접근 권한 철회와 삭제

운영자는 언제든 Google 계정의 서드파티 액세스 관리에서 이 앱의 권한을 철회할 수 있습니다. 철회하거나 앱 사용을 멈추면 로컬에 저장된 토큰과 기록을 삭제합니다.
